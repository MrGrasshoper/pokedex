# Pokedex

A Python script that fetches Pokémon data from the [PokeAPI](https://pokeapi.co/).

## Features

- Fetch Pokémon data by name
- Display ID, types, and abilities
- Simple and clean output

## Usage

```bash
python pokedex.py
```

## Requirements

- Python 3.x
- requests library

```bash
pip install requests
```
